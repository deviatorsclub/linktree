# Deviators Club Linktree

Official linktree implementation for Deviators Club.
Live at: [linktree.deviators.club](https://linktree.deviators.club)

## Overview

A modern, responsive link portal built with Next.js 16 and Tailwind CSS 4. Features a fluid glassmorphism interface and optimized SEO metadata.

## Tech Stack

- **Framework**: Next.js 16 (App Router)
- **Language**: TypeScript (ES2022)
- **Styling**: Tailwind CSS 4
- **Animations**: Framer Motion
- **Icons**: Lucide React & React Icons
- **Fonts**: Zalando Sans

## Development

```bash
# Install dependencies
npm install

# Run development server
npm run dev

# Build for production
npm run build
```

## Configuration

To modify social links, edit `src/data/links.tsx`.
Global styles and Tailwind configurations are managed in `src/app/globals.css`.
